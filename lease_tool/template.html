Charge Mappings — teach the reconciler your charge names

Charges are grouped into categories before comparing amounts, so "Trash Fee" on one document and "Valet Trash" on the other are recognized as the same charge. Add your own aliases below if the reconciler misses a naming variation — changes apply immediately to any results already on screen.

Option Filters — choose what doesn't get analyzed

Tick anything you don't want flagging a unit — every check and every charge type this tool scans is listed, including move-in specials. Useful when something is reviewed by hand on a separate schedule and you don't want it cluttering these results. Nothing is ever deleted: ticked items still show (muted) in that unit's own detail, and the true total always appears above your results. Changes apply immediately and are remembered on this device.

$

Filled in automatically from each lease's Special Provisions (Par. 32) when it states one — you shouldn't need to type anything. Used to tell a real month-to-month fee apart from ordinary rent drift. If a resident's lease term has ended and no fee anywhere near this amount is on the Rent Roll, that's reported as a missing month-to-month fee rather than quietly excused. Leave at 0 if the lease doesn't state one and this property doesn't charge one.
